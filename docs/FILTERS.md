# Комбинированные и сохранённые фильтры · 0.18

## Проверка живого эталона

GanttPRO проверен через публичный интерфейс в **headless**-браузере. Панель содержит поиск, тип, исполнителя, статус, приоритет, создателя, диапазоны дат, цвет и просроченные задачи; есть выбор/сохранение набора и очистка.

В синтетическом проекте одновременно выбраны имя `компонент` и тип **Веха**: осталась веха `2.3 Приобретение компонентов` с родителем `Подготовка`. Очистка вернула обычное дерево. Проверка не использовала исходники, внутреннее состояние приложения или его ассеты.

**Уточнение сортировки:** кнопка «Каскадная сортировка» открывает подтверждение структурного действия, а не редактор нескольких ключей/направлений. После одного подтверждённого запуска видимый порядок этого примера остался прежним. Алгоритм этим опытом не установлен; сортировка остаётся открытым пунктом, а не реализуется по догадке.

## Использование в Desktop

1. **Фильтр → Расширенные и сохранённые…**
2. Выберите значения списков и, при необходимости, границы дат.
3. **Применить** меняет вид. **Отмена / Escape**, закрытие окна или загрузка другого проекта отбрасывают черновик.
4. **Очистить условия** очищает только черновик; подтвердите кнопкой **Применить**. В меню **Очистить все условия** сразу сбрасывает действующие условия, включая поиск и быстрый фильтр.

Нативный QWidget-диалог использует стандартные элементы, системный шрифт, общую светлую/тёмную палитру и модальность относительно окна диаграммы. Даты выбираются через настоящие Qt-календари. Окно прокручивается при нехватке высоты.

### Правила

- Между полями — **И**, между отмеченными значениями одного списка — **ИЛИ**. Пустой список не ограничивает поле.
- Тип: задача/веха. Исполнитель: любой из выбранных ID; **Не назначен** можно совместить с выбранными людьми. Выбор исполнителей не создаёт новых людей и не отправляет приглашений.
- Статус различает «Выполнено» и «Закрыт». Приоритет и RGB-цвет также поддерживают несколько значений; регистр букв HEX не влияет на совпадение.
- Существующий поиск по имени/исполнителю/описанию сохраняется. Совпадение имени группы распространяет текстовый поиск на её потомков, но **не обходит остальные условия**.
- Быстрые фильтры завершения/просрочки пересекаются с расширенными. Просрочка: незавершённая задача с окончанием или дедлайном раньше текущей даты.
- **Диапазон** проверяет пересечение задачи с включительным календарным диапазоном. **Начало** и **Завершение** проверяют соответствующую дату. Все три диапазона можно сочетать; каждая граница необязательна. Перевёрнутые/невалидные диапазоны не применяются.
- Подходящие задачи показываются вместе с цепочкой родительских групп, даже если группы были свёрнуты. WBS и порядок дерева не меняются. Очистка восстанавливает состояние сворачивания.
- Строки групп и общий итог продолжают показывать **полные** суммы; загрузка ресурсов и критический путь тоже рассчитываются по всему проекту. Фильтр не является пересчётом или выравниванием расписания.
- Связь со скрытым концом не подменяется стрелкой к видимому родителю. Массовая отметка отфильтрованной группы не захватывает скрытых потомков; защищённое удаление сохраняет их и необходимую группу.
- Экспорт «Видимые задачи» фиксирует отфильтрованный набор. «Весь проект» и фиксированные полноиерархические пресеты по-прежнему используют всё дерево.

### Именованные наборы

В редакторе введите имя и нажмите **Добавить набор**. Выбор набора загружает его условия в черновик; **Удалить набор** удаляет выбранное определение из черновика. Окончательно все изменения наборов записываются в проект только после **Применить**, одной операцией Undo/Redo. Отмена отбрасывает и эти изменения.

Названия уникальны без учёта регистра. Перезаписи существующего имени нет: удалите старый набор явно либо создайте другой. Для обновления условий можно удалить выбранный набор и добавить его под тем же именем до применения.

- Применение/очистка условий — состояние окна: не меняет задачи, dirty-флаг или историю.
- Создание/удаление определений — данные проекта: dirty-флаг, Save/Discard/Cancel и Undo/Redo работают обычно.
- Undo возвращает определения, **не переключает текущий вид**. При открытии файла условия сбрасываются, а сохранённые определения остаются доступными.
- ID удалённого ресурса не заменяется на «Все»: такой выбор остаётся в наборе, отображается как «Удалённый ресурс» и сам не даёт совпадений. Это исключает незаметное расширение выборки; Undo удаления ресурса снова делает совпадения возможными.
- Данные копируются при применении, сохранении и восстановлении, без общих изменяемых списков.

## Файл и границы

Нативная **schema 9** добавляет `saved_filters`; читаются схемы **1–9**, отсутствие поля означает пустой список наборов. Версии Desktop до 0.18 не читают schema 9 — сохраняйте отдельную копию при переходе. CSV/XLSX/XML не хранят определения фильтров; полный перенос этих настроек — только `.gantt.json`.

Не заявлены фильтрация по аккаунту-создателю/дате создания, произвольным пользовательским полям, относительные даты и общие серверные наборы. Отдельной сущности аккаунта в Desktop нет. Каскадная сортировка ещё не добавлена.

## Проверки

`tests/test_filters.py` проверяет сочетания, включительные/односторонние даты, поиск групп, скрытые концы стрелок, безопасное массовое удаление, глубокие копии, ошибки, schema 1–9, Save/reopen, Undo/Redo и замороженный экспорт.

`tests/test_filters_ui.py` проверяет реальные меню и нативные элементы в обеих темах при ширинах 1000/1366/1920, Apply/Cancel/Escape, сохранение/выбор/удаление черновиков наборов, календарь, ошибки, синхронизацию поиска/быстрого фильтра и закрытие при смене проекта/скрытии окна. Проверки выполняются на частном Xvfb с Qt offscreen/software, не на рабочем столе пользователя.
